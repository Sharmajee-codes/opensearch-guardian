# Support

## Where to Ask Questions

For questions, discussions, and community support, please use:

- **GitHub Issues**: For bug reports, feature requests, and general questions
- **GitHub Discussions**: For open-ended conversations, show-and-tell, and community support

## No Hosted or Paid Support

OpenSearch Guardian is an open-source project that must be usable with zero purchase per the Open-Source Strategy (SOP section 9). There is no hosted version, paid support tier, or mandatory commercial offering.

## Community Support

The project relies on community support through:
- GitHub Issues and Discussions
- Documentation in the `docs/` directory
- Example configurations and tutorials
- Community-maintained resources

## Enterprise Support

Organizations requiring commercial support, SLAs, or dedicated assistance should consider:
- Engaging with OpenSearch-related service providers
- Contracting with OpenSearch consultants
- Developing internal expertise using the open-source codebase

## Getting Help Effectively

To get the best support from the community:

1. Search existing issues and discussions before posting
2. Provide clear, reproducible steps for bugs
3. Include relevant version information and environment details
4. Be respectful and patient with volunteer maintainers
5. Consider contributing fixes or improvements back to the project

## Security Issues

For security vulnerabilities, please see [SECURITY.md](SECURITY.md) for private reporting procedures.
